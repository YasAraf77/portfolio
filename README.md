# Yasar Arafath — Portfolio Website

A responsive, static personal portfolio built with HTML, CSS, and a small amount of JavaScript.

## Preview locally
Open `index.html` in your browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Verify company names, job titles, dates, and project descriptions.
3. Add approved project screenshots or links if you have them.
4. If desired, update the page title and meta description.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `yasar-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide your public website URL after deployment.

The site uses Google Fonts when online; system fonts will be used if they are unavailable.
